# PDFScanner

## About
This takes an image of a paper (4 sided object) as an input and does its magic, The image can be missaligned or a distance away, the only requierment is the paper 4 sided object must be completly in frame.
1. Corrects misaligned Image.
2. Converts it to black and white.
3. Outputs it in a similar format to a scanned copy, also allows for outlines.
